# Westfield AES

Responsive static website built from the supplied Google Stitch desktop and mobile designs.

## Run locally

From this directory:

```bash
npm install
npm run dev
```

Then open `http://localhost:4173`.

## Pages

- `/`: Homepage
- `/about.html`: Company story
- `/contact.html`: Contact form
- `/legal.html`: Privacy policy and terms

The contact form validates required fields and opens the visitor's email client with a pre-filled message to `contact@westfieldaes.com`. Replace that behavior with a production form endpoint when one is available.
